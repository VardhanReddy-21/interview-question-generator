C Programming

malloc vs calloc

Click card to reveal answer...

malloc: Allocates raw bytes; memory contains garbage values.

calloc: Allocates elements and initializes all bytes to zero.

C++

Smart Pointers (RAII)

Click card to reveal answer...

unique_ptr: Exclusive ownership, zero overhead, move-only.

shared_ptr: Reference-counted ownership.

weak_ptr: Breaks circular reference memory leaks.

Python

CPython GIL

Click card to reveal answer...

GIL: Mutex preventing multiple threads from running Python bytecode concurrently.

Use multiprocessing for CPU-bound tasks and asyncio/threading for I/O tasks.

Java

HashMap & Java 8

Click card to reveal answer...

Buckets use Linked Lists for collisions.

When bucket exceeds 8 elements, it upgrades to a Red-Black Tree, dropping lookup from O(n) to O(log n)!

SQL

WHERE vs HAVING

Click card to reveal answer...

WHERE: Filters rows before aggregation & grouping.

HAVING: Filters groups after GROUP BY aggregation.

Data Structures

Array vs Linked List

Click card to reveal answer...

Array: Contiguous memory, O(1) random access, great CPU cache locality.

Linked List: Scattered memory, O(N) access, O(1) insertion at pointer.
